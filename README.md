# Pokédex

App sencilla para buscar Pokémon usando la [PokéAPI](https://pokeapi.co/).

## Funciones

- Buscador por nombre o número que filtra mientras escribes.
- Cuadrícula con sprite, número y nombre.
- Al hacer clic (o pulsar **Buscar**) muestra el detalle: imagen, tipos, altura, peso y estadísticas.

## Cómo usarla

Abre `index.html` en el navegador, o sírvela localmente:

```bash
python3 -m http.server 8000
```

y visita http://localhost:8000.
